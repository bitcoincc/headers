Verification

Headers are self-verifying via proof-of-work. Any mirror can be validated:

1. Each header's hash meets the difficulty target

2. Each header references the previous header's hash

3. Chain forms continuous proof-of-work from genesis

4. Compare against multiple sources

5. If any source lies, the math breaks

You don't trust mirrors. You verify headers.
